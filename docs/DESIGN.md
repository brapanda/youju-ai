# 首版界面范围与设计依据

## 参考素材

已查看用户提供的首页视频（约 8 秒）及地图／物业浏览视频（约 36 秒），并参考对话中的六张截图。

保留：旧版约 `#0ECD87` 绿色识别、搜索、出售／出租、房源图片浏览、地图标记与底部卡片。视觉重新设计：暖白／墨绿背景、柔和绿色、留白、圆角图文卡片、悬浮胶囊底栏。

底栏顺序：首页、地图、AI 找房、收藏、我的。不是对其他产品的品牌、图标或内容复制。

## 当前实现

- 首页：品牌、区域提示、搜索、交易筛选、精选卡片、地图／AI 入口。
- 地图：示意地图可交互；Flutter 接口预留真实 Mapbox；筛选、选点、底部预览、列表切换。
- 简洁物业浏览：照片、价格、地址、卧室／卫浴／面积、收藏及图库。
- 浅色／深色：暖白及深墨绿两套主题；不以纯黑／刺眼荧光作为大面积背景。
- 收藏：仅本地预览状态；浏览器保存在 localStorage，Flutter 在内存。
- 个人／AI：诚实的基础入口，不模拟已连接的账户或模型。

## 暂缓

真实 AMPRE 房源与地理编码、数据库、服务端空间查询与聚合、设备定位、学校排名／犯罪统计、新闻、账户／推送、多语言文案、经纪联系和上架发布。

## 必须保留的边界

演示地图不是实测地理范围；原生 Mapbox 分支仍需公开 Token、网络和平台构建验证。房源属性是合成数据；视频图片仅内部设计参考，不代表其匹配房源。用户旧 MySQL 和 Swift 工程未改动。

浏览器设计稿与 Flutter 是不同运行产物。前者用于立即评审方向，后者是后续移动端开发的基础，当前排版并非逐像素一致。
